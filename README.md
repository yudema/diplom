# Инструкция по запуску информационной системы "BustCom"

Добро пожаловать! Это руководство поможет вам запустить учебную платформу "BustCom" на вашем компьютере.

## Веб-доступ к системе "BustCom"

### Облачная версия (если доступна)
Если для "BustCom" развернута облачная версия, она может быть доступна по адресу:
http://79.137.192.29:8000/
*(Если этот адрес не актуален или облачной версии нет, этот абзац можно изменить или удалить)*

### Локальная версия (запуск на вашем компьютере)
Это основной способ запуска для тестирования и доработки. Следуйте шагам ниже.

## Что вам понадобится (Требования)

1.  **Компьютер**:
    *   Процессор: от 2 ядер
    *   Оперативная память (ОЗУ): от 4 ГБ
    *   Свободное место на диске: около 10 ГБ (для проекта и зависимостей)

2.  **Программы**:
    *   **Python**: Нужна определенная версия. Убедитесь, что он установлен. Если нет, скачайте с [python.org](https://www.python.org/).
        *   **ВАЖНО**: Проекту требуется Python версии **`3.13`** (Пожалуйста, убедитесь, что это актуальная и стабильная версия Python, необходимая для проекта. Например, `3.10.x`, `3.11.x`, `3.12.x`).
    *   **Pip**: Менеджер пакетов Python. Обычно устанавливается вместе с Python.
    *   **Веб-браузер**: Любой современный (Google Chrome, Firefox, Edge и т.п.).

## Запускаем "BustCom" шаг за шагом

Представьте, что вы только что получили папку с проектом (например, скачали и распаковали архив). Эта папка называется `ulichkomuniti`.

1.  **Откройте Командную Строку и Перейдите в Папку Проекта**
    *   Откройте терминал вашего компьютера (Командная строка (CMD) или PowerShell в Windows, Терминал в Linux/macOS).
    *   Используйте команду `cd`, чтобы перейти в папку `ulichkomuniti`. Например:
        ```bash
        cd C:/Путь/К/Папке/ulichkomuniti
        ```
        Или для Linux/macOS:
        ```bash
        cd ~/Путь/К/Папке/ulichkomuniti
        ```
        *(Замените `Путь/К/Папке/` на ваш реальный путь к папке `ulichkomuniti`)*

2.  **Создайте и Активируйте Виртуальное Окружение (Это важно!)**
    Чтобы не смешивать библиотеки этого проекта с другими, создадим для него "песочницу" – виртуальное окружение. Находясь в папке проекта, выполните:
    ```bash
    python -m venv venv
    ```
    Эта команда создаст папку `venv` внутри вашего проекта.
    Теперь активируйте его:
    *   **Windows (CMD/PowerShell):**
        ```cmd
        .\venv\Scripts\activate
        ```
    *   **Linux/macOS (bash/zsh):**
        ```bash
        source venv/bin/activate
        ```
    После активации вы увидите `(venv)` в начале строки вашего терминала.

3.  **Установите Все Необходимые Библиотеки**
    В папке проекта должен быть файл `requirements.txt`. Он содержит список всех библиотек, нужных "BustCom". Установим их одной командой (убедитесь, что виртуальное окружение активировано):
    ```bash
    pip install -r requirements.txt
    ```
    Дождитесь окончания установки.

4.  **Подготовьте Базу Данных (Используем Готовый Дамп SQLite)**
    Вам не нужно создавать базу данных с нуля или регистрировать пользователей – все уже готово в специальном файле (дампе).
    *   В вашем пакете с проектом (в папке `ulichkomuniti`) должен быть файл с данными вашей SQLite базы данных. **Как он называется?** (Например, `backup.sqlite3`, `project_data.db`, или он уже `db.sqlite3`?)
    *   **ВАЖНО:** Скопируйте этот файл (если он не в корне `ulichkomuniti`) в **корневую папку вашего проекта `ulichkomuniti`** (туда же, где лежит файл `manage.py`).
    *   **ВАЖНО:** Переименуйте скопированный файл в `db.sqlite3` (если он изначально называется иначе). Именно это имя (`db.sqlite3`) ожидает проект по умолчанию для SQLite.
        *(Если ваш проект настроен на другое имя файла БД в `settings.py`, укажите это здесь и измените инструкцию соответственно.)*

5.  **Примените Миграции (На всякий случай)**
    Этот шаг синхронизирует состояние базы данных с моделями в коде. Даже с дампом, это полезная команда.
    ```bash
    python manage.py migrate
    ```

6.  **Запустите Сервер Разработки**
    Теперь все готово к запуску!
    ```bash
    python manage.py runserver
    ```
    Вы должны увидеть сообщения о том, что сервер запущен, обычно на адресе `http://127.0.0.1:8000/`.

7.  **Откройте "BustCom" в Браузере**
    Откройте ваш любимый веб-браузер и перейдите по адресу:
    [http://127.0.0.1:8000/](http://127.0.0.1:8000/)
    Вы должны увидеть главную страницу платформы "BustCom".

## Как остановить локальный сервер

*   Вернитесь в окно терминала, где вы запускали `python manage.py runserver`.
*   Нажмите комбинацию клавиш `Ctrl+C`.
